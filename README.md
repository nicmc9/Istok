# Istok

Игровой движок на Rust. Графика через wgpu: Vulkan, Metal, GLES 3.2 и WebGPU.
Собирается на macOS, Linux, Android, iOS и в браузере.

Подсистемы — отдельные крейты. Игра подключает нужные плагинами и feature-флагами.
Физика и звук спрятаны за трейтами: реализацию можно сменить, не переписывая игру.
Логика идёт фиксированным шагом, отрисовка — в отдельном потоке.

## Возможности

- Окно, ввод и жизненный цикл на всех платформах
- 3D: PBR, материалы, направленный и точечный свет, тени, камера
- 2D: спрайты, атласы, ортографическая камера
- Скелетная анимация и покадровая анимация спрайтов
- Текст и шрифты
- Частицы и декали
- Постэффекты: HDR, bloom, FXAA
- Внеэкранный рендер и скриншоты
- Ресурсы: glTF, PNG/JPEG, KTX2 (Basis Universal), шейдеры, шрифты; горячая перезагрузка на desktop
- Загрузка по сети с дисковым кешем, докачкой и проверкой SHA-256
- Сцены в RON: сохранение и загрузка
- Физика твёрдых тел (Rapier) и звук (kira) — подключаются отдельно
- Отладочный интерфейс, консоль и переменные конфигурации (CVar)
- Логи и профилирование через Tracy

Запуск примера: `cargo run -p sandbox`. Сборка остальных платформ — в [docs/building.md](docs/building.md).
